# Image credits

Every photograph in this game is either public domain or under a Creative
Commons licence that permits reuse. Each image was cropped square
(subject-centred) and resized to 640 × 640.

Images come from two places:

- **Wikimedia Commons** — <https://commons.wikimedia.org>
- **Openverse** — <https://openverse.org>, restricted to CC0 and
  Public Domain Mark

Where a licence requires attribution (any CC BY / CC BY-SA row below), the
author is named here, which is how attribution is provided for this work.
CC0 and public-domain images need no attribution, but the creators are
credited anyway. "Unknown" means the source record carries no creator name.

Levels drawn in CSS — **Numbers**, **Letters** and **Colors** — use no
photographs at all.

Every image is stored in this repository. Nothing is hotlinked, so the game
keeps working with no network and no card can ever break.

Retrieved July 2026.
